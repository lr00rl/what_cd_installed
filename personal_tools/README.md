# Personal Tools

Small personal tools and shell snippets that are useful to keep, but should not
be loaded automatically by the dotfile shell startup path.

Use this directory for:

- small one-off utilities
- sourceable shell functions
- executable scripts that are useful enough to keep but not important enough to
  install into `~/bin`
- notes about how to restore or run the tool

These tools are intentionally independent from `cdxx0-dotfile`. Restore this
repository when you want the code; wire a tool into shell startup only after it
becomes part of daily use.
